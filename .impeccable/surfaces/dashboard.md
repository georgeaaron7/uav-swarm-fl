# SwarmCompute dashboard

## Mode
Operate. Researchers check the queue and recovery status, then inspect a worker or scientific run. Owners control their own participation.

## Direction contract
THESIS: A compact operations console makes independent simulations and their authoritative recovery points inspectable. Real queue state leads the first viewport.
OWN-WORLD: Blue slate surfaces (#151e2a, #1b2736), pale blue actions, restrained green/amber/red status semantics, system UI typography and tabular measurements. Dense tables remain readable; controls retain familiar labels.
STORY: Read terminal progress, distinguish divergence from failure, inspect the queue, then connect or pause workers with explicit owner permissions.
FIRST VIEWPORT: Persistent 226px navigation, 62px connection bar, a broad terminal-progress strip, four aligned capacity/throughput measurements, studies and real activity. Primary actions sit alongside each section's task.
FORM: User-pinned compact dark operations console; code-first selected explicitly. Direction seed c529b25c was run; the supplied PRD and user's specified construction choice take precedence over ornamental catalog directions.
SIGNATURE INTERACTION: Completed-round events refresh queue state and charts through authenticated SSE, with visible polling fallback; no fabricated activity or decorative motion. Navigation collapses to a drawer on narrow screens.
